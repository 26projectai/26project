## Genre and settings
- **Genre:** Obby & Platformer. **Subgenre:** Tower / Difficulty Chart, if offered.
- **Devices:** Computer, Phone, Tablet, Console (most players are on mobile).
- **Max players:** 20–30, so the live race and co-op have people.
- **Age guidelines:** complete the questionnaire. The game has mild cartoon peril only.

## Tags / keywords to use in the description

jump power, troll obby, funny
